# Career Atlas

**收藏职位，读懂职位，追踪投递，永不丢失上下文。**

[English →](README.md)

Career Atlas是一个私有、本地优先、中英双语的求职管理工作台。它作为网站运行在你自己的电脑上（`http://127.0.0.1:4310`），所有修改自动保存到本地SQLite数据库，并每周进行加密备份。无需云账号、服务器或订阅；也可以选择通过你自己的Claude Code登录使用AI解析。

粘贴职位链接后，系统会立即保存，并在后台读取招聘页面。每个提取出的字段都会附上来源和原文引用，经你核对后才正式存入。之后，你可以追踪这次申请的每个阶段，全部历史都可追溯。

> 当前状态：预发布（v0.2，本地优先），单用户。已实现、已测试、已部署的内容见[HANDOFF.md](HANDOFF.md)。

## 主要功能

- **先保存，再丰富**：支持职位链接、粘贴JD和手动录入三种方式。即使网页无法读取，链接也不会丢失。
- **如实提取**：依次尝试以下来源：公开ATS接口（Greenhouse、Lever、Ashby、SmartRecruiters、Workday）、schema.org `JobPosting`结构化数据、网页正文。之后再用规则提取，并可选AI提取。
  - 每个字段都记录来源、证据原文、可信度和核对状态。
  - 未知就是未知。AI给出的薪资、签证等信息，如果在原文中找不到对应引用，会被直接丢弃。
- **AI草稿（Claude Desktop或任意AI）**：通过一个小型Claude Desktop扩展，让Claude研究职位并以草稿形式发送到本地Career Atlas；也可以把任意AI的回答粘贴到“从AI导入”。每个值都标明“原文已核实”“来自网页”或“AI推断”，核对并保存前不会写入。Claude会在同一次处理中给出描述性字段的英文和简体中文版本，职位内容会随界面语言切换（原文与证据保持不变）。无需API密钥，也没有额外费用。
- **我的档案与职位匹配**：记录学历、经历、技能、证书、语言、驾照和工作许可（也可以通过Claude从简历导入，逐项核对）。之后每个已保存职位都会在你的电脑上与档案对比：哪些必备条件满足或不满足、优先条件、暂无法判断的内容及各自依据——未满足的必备条件单独列出，绝不会被分数掩盖。
- **人工确认**：提取结果需要你核对后才会保存。手动修改会作为覆盖值保留，同时保存原始提取结果。
  - "重新读取职位"会展示变化，由你决定是否应用。
- **收藏≠投递**：职位信息、收藏关系和投递记录分开存储。状态从已收藏、准备申请、已投递……一直到Offer、已接受、被拒绝或主动撤回。
  - 状态历史只追加、不覆盖。
- **看板**：支持拖拽和键盘操作。界面即时更新，失败时自动回滚，每次移动都会记录事件。
- **全部职位表格**：支持组合筛选。
  - 可按办公方式、最低薪资（只比较同币种、同计薪周期）、申请限制、技能、标签、日期、是否待核对等条件筛选。
  - 支持保存视图、批量操作和CSV导出。
- **职位详情**：提供证据弹窗、可搜索的原始JD快照历史（原链接失效后仍可查看），以及投递日期、时间线、笔记和提醒。
- **职位对比**：最多4个职位并排比较，附带可解释的偏好评分。评分不代表录取概率。
- **日程与时间线**：月视图和列表视图，支持提醒、可配置的跟进周期和`.ics`导出。
- **求职分析**：每个比率都标明分子和分母。转化按"首次到达阶段"计算，所以面试后被拒的申请仍计入面试转化。
- **求职材料**：简历和求职信版本保存为本地文件（不会上传），并可关联到投递记录。
- **自动保存**：界面显示“正在保存/已保存/保存失败”；有未保存的文字时关闭页面会先提示。
- **数据备份**：每周自动加密备份并自我校验（保留26份），设置页可“立即备份”和“测试恢复”；另支持JSON/CSV导出，以及带预览、自动跳过重复的JSON导入。

## 不做的事情

Career Atlas不会：

- 绕过登录、验证码或反爬机制
- 自动抓取LinkedIn、Indeed或Glassdoor页面（平台条款禁止；请改为粘贴JD）
- 猜测薪资
- 预测录取结果
- 代你投递

Gmail、Google日历和浏览器扩展属于后续规划，**目前没有实现**。

## 快速开始

需要macOS（Linux也可运行，但没有启动器）和Node.js 22.16或更高版本。

```bash
git clone https://github.com/<你的账号>/career-atlas.git && cd career-atlas
npm install
npm run start:local -- --open        # 首次运行会自动构建，然后打开 http://127.0.0.1:4310
npm run launcher:install             # 可选（macOS）：创建“Career Atlas”应用，双击即可启动并打开浏览器
```

数据保存在`~/Library/Application Support/CareerAtlas/`，位于源代码目录之外，因此更新或重新克隆代码都不会影响数据。每个克隆项目的人都会得到自己独立的空数据库。数据位置、备份与恢复以及可选的Claude AI说明见 **[docs/LOCAL_FIRST.md](docs/LOCAL_FIRST.md)**（英文）。

常用命令：`npm run stop:local`（停止）、`npm run local -- status`（状态）、`npm run local -- backup`（立即备份）、`npm run dev`（开发模式，使用独立的开发数据库）。
